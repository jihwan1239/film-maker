# 흥행제작소

반지하 원룸에서 시작해 천만 영화를 만드는 픽셀 영화사 경영 게임이에요.
Kairosoft의 '게임개발스토리'에서 영감을 받아 만들었고, 브라우저에서 바로 플레이할 수 있는 웹앱이에요.

## 어떤 게임인가요

영화사 대표가 되어 직원을 뽑고, 작가와 감독진과 배우를 섭외하고, 투자를 받고 배급사와 계약해서 영화를 만들어요.
장르와 소재를 어떻게 조합하느냐, 누구를 캐스팅하느냐, 언제 개봉하느냐에 따라 흥행이 갈리고 마지막엔 운도 따라요.
돈을 모으면 더 넓은 사무실로 이사하고 더 많은 직원을 둘 수 있어요.

## 주요 기능

**영화 제작**
- 장르 10개와 소재 20개를 조합해요. 소재 절반은 잠겨 있다가 기획개발 능력이 좋은 직원이 가끔 찾아내요.
- 조합마다 궁합이 숨겨져 있고, 개봉하고 나면 조합 도감에 별점으로 기록돼요.
- 제작은 시나리오 개발, 촬영, 후반작업, 개봉 준비 4단계로 진행되고, 규모에 따라 16주에서 34주가 걸려요.
- 흥행 요소는 스토리, 연기, 연출, 영상미, 사운드, 특수효과, 화제성 7가지예요. 장르마다 중요한 요소가 달라요.

**사람들**
- 제작사 직원은 마케팅, 캐스팅, 배급, 투자유치, 기획개발, 제작관리를 맡아요.
- 감독은 총괄, 촬영, 미술, 음향, CG 다섯 종류이고, 작가와 함께 전속으로 뽑거나 작품마다 외주로 섭외할 수 있어요.
- 채용 공고를 내면 3~4주 뒤에 지원자 3명이 와요. 비싼 공고일수록 실력 좋은 사람이 와요.
- 배우는 주연과 조연을 따로 캐스팅해요. 캐스팅 역량이 높아야 유명 배우를 섭외할 수 있어요.
- 뽕준호, 킴은숙, 쏭강호 같은 패러디 거장들도 등장해요.

**투자와 배급**
- 투자자는 제작비 일부를 내주는 대신 수익을 나눠 가져요. 투자유치 능력이 높을수록 큰 투자자와 좋은 조건을 잡을 수 있어요.
- 극장 개봉 때는 배급사를 골라요. 큰 배급사일수록 상영관이 많지만 수수료도 높고, 협상력이 있어야 계약해줘요.
- OTT 판매는 정해진 금액을 바로 받는 대신 흥행 보너스가 없어요. 가끔 OTT에서 특정 장르 의뢰가 들어와요.
- 여름 성수기, 명절, 연말처럼 시즌마다 잘 되는 장르가 다르고 해마다 유행 장르가 바뀌어요.
- 흥행작은 속편을 만들 수 있고, 매년 연말에는 황금복숭아 영화제가 열려요.

**회사 성장**
- 반지하 원룸, 상가 사무실, 강남 빌딩, 자체 촬영 스튜디오 순으로 이사해요.
- 사무실마다 인테리어가 바뀌고, 개봉한 영화 포스터와 트로피가 벽에 걸려요.

**그 밖에**
- 칩튠 배경음악과 효과음 (회사 탭에서 따로 끌 수 있어요)
- 진행 상황은 브라우저에 자동 저장돼요
- 휴대폰 홈 화면에 앱처럼 설치할 수 있어요

## 홈 화면에 설치하기

- 아이폰: 사파리로 접속한 뒤 공유 버튼을 누르고 '홈 화면에 추가'
- 안드로이드: 크롬으로 접속한 뒤 메뉴에서 '앱 설치' 또는 '홈 화면에 추가'

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 게임 전체 (화면, 그래픽, 사운드, 게임 로직) |
| `manifest.json` | 홈 화면 설치 정보 |
| `sw.js` | 오프라인 실행용 서비스워커 |
| `icon-192.png`, `icon-512.png` | 앱 아이콘 |
| `icon-maskable-512.png` | 안드로이드용 아이콘 |
| `apple-touch-icon.png` | 아이폰 홈 화면 아이콘 |

그래픽과 사운드는 이미지나 음원 파일 없이 코드로 직접 그리고 연주해요.

## 배포 방법

1. GitHub에 새 저장소를 만들고 위 파일들을 루트에 올려요.
2. 저장소의 Settings에서 Pages로 들어가요.
3. Branch를 `main`, 폴더를 `/ (root)`로 정하고 저장해요.
4. 잠시 뒤 표시되는 주소로 접속하면 바로 플레이할 수 있어요.

게임을 수정한 뒤에는 바뀐 파일만 다시 올리면 돼요. 디자인이나 기능이 크게 바뀌었을 땐 `sw.js` 안의 캐시 이름 숫자(`heunghaeng-v7`)를 하나 올려주면 이전 버전이 남지 않아요.

## 로컬에서 실행하기

서비스워커 때문에 파일을 더블클릭하는 대신 간단한 서버로 여는 게 좋아요.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`으로 접속하면 돼요.

## 참고

- 게임 속 인물 이름은 실제 영화인의 이름을 재미로 바꾼 패러디이고, 실제 인물과는 관계가 없어요.
- 게임 속 OTT 이름과 영화제 이름도 모두 가상이에요.
